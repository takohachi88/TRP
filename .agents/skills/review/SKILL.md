---
name: review
description: この会話で対応した変更を、依頼内容とのずれ、不具合、回帰、検証の不足がないかレビューするときに使う。
---

1. 会話の依頼、合意した仕様、作業記録から対象を特定する。`git status --short`、`git diff`、`git diff --cached` と今回追加した未追跡ファイルの内容を確認する。既存の別作業が混在する場合は、今回の対応分に絞る。対象を特定できない箇所があれば、その範囲を明示する。
2. 差分と関連する呼び出し元を読み、依頼を満たすか、既存の動作を壊さないかを確認する。ファイルと Git インデックスに対して読み取り専用で作業する。
3. 指摘は重要度順に並べ、各項目にファイルと行番号、問題が起きる条件、影響を記載する。指摘がなければその旨を伝え、必要な検証が未実施なら明記する。
